MODELO EN CASCADA

Características

  • Secuencia Lógica: No hay solapamiento entre fases (Requisitos -> Diseño -> Implementación -> Pruebas -> Mantenimiento).
  • Documentación Rigurosa: Cada fase genera un entregable formal que actúa como base para la siguiente.
  • Requisitos Estáticos: Se definen y "congelan" totalmente al inicio del proyecto; no admite cambios sobre la marcha.
  • Hitos Claros: Facilita el control del cronograma y presupuesto mediante metas bien definidas.
